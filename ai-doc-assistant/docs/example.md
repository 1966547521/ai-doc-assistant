# AI 智能文档助手说明文档

## 项目简介

AI 智能文档助手是一个基于 Retrieval-Augmented Generation (RAG) 技术的智能问答系统。

## 核心功能

### 1. 文档上传
支持多种文档格式：
- PDF 文件
- 纯文本文件 (.txt)
- Markdown 文件 (.md)

### 2. 文档解析
系统会自动解析上传的文档，提取文本内容，并进行分段处理。

### 3. 智能检索
使用向量数据库进行语义检索，快速定位相关文档片段。

### 4. 智能问答
基于检索到的文档内容，使用大语言模型生成精准回答。

## 技术栈

- **框架**: LangChain
- **向量数据库**: Chroma
- **大语言模型**: DeepSeek
- **前端**: Streamlit

## 使用流程

1. 在侧边栏上传文档
2. 点击"处理文档"按钮
3. 在问答区域输入问题
4. 查看 AI 生成的回答

## 注意事项

- 支持的文件大小建议不超过 50MB
- 建议上传结构化的技术文档或手册
- 系统会自动保存索引，下次访问时无需重新上传
